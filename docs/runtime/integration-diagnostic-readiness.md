# Integration Diagnostic Readiness

Release-readiness evidence can include Roadmap 42 diagnostic and smoke outcomes for
supported domains. Reviewers must be able to identify domains that passed, failed, were
blocked, were skipped, are limited, or are deliberately unsupported.

Rollback disables diagnostic run creation, hides new diagnostic projections, and stops
smoke publication while preserving existing integration execution and already-written
audit evidence for authorized operators until retention expiry.
